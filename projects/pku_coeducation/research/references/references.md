# References

## Primary sources

1. **《北京大學日刊》第559號, 11 March 1920, 第2版, 「本校女生消息」 /
   「女學生一覽表」.** Internet Archive, item `beida-rikan-1920.03.11`.
   <https://archive.org/details/beida-rikan-1920.03.11>
   — University notice + table; the women are recorded as 旁聽生 (auditors).
   Local copy: `../sources/raw/beida-rikan-1920-03-11-559-p2.jpg`.

2. **蔡元培, 〈我在北京大學的經歷〉 (1934).** Wikisource.
   <https://zh.wikisource.org/wiki/我在北京大學的經歷>
   — Cai Yuanpei's own account: "九年，有女學生要求進校，以考期已過，姑錄為
   旁聽生。及暑假招考，就正式招收女生。"

3. **〈鄧春蘭女士來書請大學解除女禁〉,《晨報》(Beijing), 3 Aug 1919**, and
   the same letter in 上海《民國日報》, 8 Aug 1919. Quoted and reprinted in the
   sources below; the original run is not freely digitised.
   — The student petition that started the campaign.

4. **上海《民國日報》, 3 March 1920**, report on the first women at Peking
   University (王蘭 in 哲學系, 奚湞/查曉園 in 英文系). Quoted in the Wikipedia
   article on 京師大學堂, note 42.
